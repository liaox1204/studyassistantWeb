# AI 小学学习助手 — 前端（Vue 3）

面向小学 1–3 年级学生的 AI 学习辅助应用前端，覆盖**语文、数学、英语、AI 智能老师、错题本**五大模块。

技术栈：Vue 3（Composition API + `<script setup>`）+ Vite + Vue Router + Pinia + Element Plus + Axios。

---

## 1. 目录结构

```
src/
├── api/
│   ├── request.js        # axios 实例：自动附加 JWT、统一解包响应
│   └── index.js          # 各模块接口封装
├── assets/
│   └── main.css          # 全局样式（儿童友好配色）
├── layouts/
│   └── MainLayout.vue    # 主布局（顶部导航 + 内容区）
├── router/
│   └── index.js          # 路由 + 登录守卫
├── stores/
│   └── user.js           # 用户登录态（Pinia）
├── views/
│   ├── LoginView.vue     # 登录 / 注册
│   ├── HomeView.vue      # 首页：学习概览 + 模块入口
│   ├── MathView.vue      # 数学：口算练习 / 题库练习 / 判分结果
│   ├── ChineseView.vue   # 语文：汉字 / 成语 / 古诗
│   ├── EnglishView.vue   # 英语：单词学习 / 单词听写
│   ├── AiView.vue        # AI 智能老师：解题 / 讲解 / 答疑
│   └── WrongView.vue     # 错题本：列表 / 重练 / 移除
├── App.vue
└── main.js
```

---

## 2. 快速开始

### 2.1 安装依赖

```bash
npm install
```

### 2.2 启动后端

前端通过 `/api` 代理访问后端，请先启动 FastAPI 服务（默认 `http://127.0.0.1:8000`）：

```bash
# 在 studyassistantServer 目录下
uvicorn app.main:app --reload --port 8000
```

### 2.3 启动前端

```bash
npm run dev
```

访问 http://localhost:5173

### 2.4 打包

```bash
npm run build
```

## 5. 功能亮点

- **练习即反馈**：口算、题库、听写提交后立即展示正确率、用时与逐题结果。
- **错题闭环**：答错自动进入错题本；错题本支持单题/整页重练，连续答对 3 次自动移出并实时提示。
- **激励闭环**：签到、积分明细、徽章、同年级排行榜；首页即可一键签到并实时刷新积分。
- **学情可视化**：知识点掌握度表格 + 雷达图、正确率趋势折线图、学科分布柱状图，全部用原生 SVG 实现，无额外图表依赖。
- **趣味练习**：60 秒倒计时口算挑战、按知识点闯关（80% 达标解锁下一关）、每日任务领取奖励。
- **角色菜单**：学生 / 家长 / 管理员按角色自动显示不同导航与首页模块，路由守卫拦截越权访问。
- **语音跟读**：汉字、古诗、英语单词支持浏览器语音朗读（Web Speech API）。
- **儿童友好 UI**：圆角卡片、柔和渐变配色、大字号题目、动画过渡。
- **登录守卫**：未登录自动跳转登录页，Token 失效自动清理登录态。

## 6. 环境说明

开发环境通过 `vite.config.js` 的 `proxy` 将 `/api` 转发到 `http://127.0.0.1:8000`。
若后端地址不同，修改该配置的 `target` 即可。生产部署建议由 Nginx 统一反向代理前后端。
